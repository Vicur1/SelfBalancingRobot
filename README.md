# Self-Balancing Robot

ELE201 semester project at Western Norway University of Applied Sciences (HVL), 2026.

A two-wheeled self-balancing robot built using an STM32F767ZI microcontroller.

### Features
- LSM9DS1 IMU with complementary filtering
- PID-based motor control using PWM
- Bluetooth remote control via HC-05
- Real-time telemetry and CSV logging
- HTML-based monitoring interface
